# Fault Geometry Tools

Tools used to build CFM fault geometries.

| Tool | Description | DOI |
|---|---|---|
| [CFM-QGIS-contours2mesh](https://github.com/cascadiaquakes/CFM-QGIS-contours2mesh) | QGIS plugin for building triangular fault-surface meshes from depth contours | [10.5281/zenodo.19900593](https://doi.org/10.5281/zenodo.19900593) |
| [cross_section_digitizer](https://github.com/cascadiaquakes/cross_section_digitizer) | QGIS plugin for georeferencing and digitizing geological cross-sections | [10.5281/zenodo.17654865](https://doi.org/10.5281/zenodo.17654865) |
| [CFM-ccfm](https://github.com/cascadiaquakes/CFM-ccfm) | Python library for building 3D fault meshes from depth contours, used by the QGIS plugin | [10.5281/zenodo.18896084](https://doi.org/10.5281/zenodo.18896084) |
| [Qgis2threejs](https://github.com/cascadiaquakes/Qgis2threejs) | QGIS plugin for previewing terrain and vector data in 3D in a web browser | [10.5281/zenodo.17654830](https://doi.org/10.5281/zenodo.17654830) |

A step-by-step [fault geometry building tutorial](https://cascadiaquakes.github.io/fault-geometry-building-tutorial/) walks through the workflow.
