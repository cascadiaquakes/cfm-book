# CRESCENT Community Fault Model Book

[![License: BSD-3-Clause](https://img.shields.io/badge/License-BSD_3--Clause-blue.svg)](LICENSE)

Documentation for the CRESCENT Community Fault Model (CFM) and its web viewer.

**Read the book:** https://cascadiaquakes.github.io/cfm-book/
**Viewer:** https://cfm.cascadiaquakes.org

---

## Contents

- **User Guide**: how to use the 2D and 3D fault viewers
- **Inclusion Criteria**: how faults are selected for the model
- **Model Data**: downloads and citation for the fault model
- **Tools**: fault geometry tools that work with the CFM

---

## Building Locally

The book is built with [MyST](https://mystmd.org). With Node.js installed, run from the repository root:

```bash
npx --yes mystmd start
```

Then open the URL it prints.

---

## Deployment

GitHub Actions builds the book on every push to `main` and publishes it to GitHub Pages.
