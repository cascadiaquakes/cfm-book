# CRESCENT Community Fault Model (cfm-book)

MyST-based JupyterBook for the CRESCENT Community Fault Model: viewer user guide, inclusion criteria, model data, and fault geometry tools.

Live site: https://cascadiaquakes.github.io/cfm-book/ (deployed on push to main)

## Local preview

```
npx --yes mystmd start
```

Then open the URL printed by `mystmd`.
